COMMON ISSUES
-------------

Q: Arthur keeps saying STAY_OUT even on good setups.
A: Check Morgan confidence score. If low, conservative mode is ON (hard rule).
   Also check kill switch status. After losses, Lancelot enforces cooldown.

Q: No trades for a long time.
A: Check trading hours -- entries only between 14:45 and 20:45 UTC.
   Check calendar -- Guinevere blocks around high-impact US data releases.

Q: Capital.com connection fails.
A: Check .env credentials. The Capital.com API can have session timeouts.
   Paper trading mode works without a live connection (yfinance fallback).

Q: Dashboard not loading.
A: Start dashboard_us.py in a separate terminal.
   Main loop and dashboard are separate processes.
   Dashboard port 5044 must not be in use.

Q: Force close not happening.
A: Force close checks continuously in the position monitoring loop.
   It triggers at 20:45 UTC -- Lancelot also blocks new entries after 20:45.
   Check UTC timezone conversion -- pytz must be installed.
